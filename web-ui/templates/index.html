Connect Spotify

This needs a Spotify app of your own — free, takes a minute.

  1. Open developer.spotify.com/dashboard and click Create app.
  2. Add this exact Redirect URI:
    …
  3. Tick Web API, save, then copy the Client ID.
  4. Put it in .env as SPOTIFY_CLIENT_ID=… and restart.

Spotify refuses localhost and requires HTTPS for anything that isn't a loopback address, so the redirect must be 127.0.0.1 and you must connect from a browser on the server itself. Once connected, the token is stored server-side and everyone else can just use it.

Get a CSV from Exportify

Use this when you would rather not connect Spotify here. Exportify is a separate site that turns a Spotify playlist into a CSV file.

  1. Open exportify.app and click Get Started.
  2. Log in with Spotify and allow read-only access to your playlists.
  3. Find the playlist you want and click its export button — a .csv file downloads.
  4. Drop that file below.
Drop the CSV here, or click to choose

The playlist name becomes the folder name, and it gets the CSV and an .m3u alongside the tracks. Tracks you already have are skipped. Exportify's CSV has no genre column, so genre tags stay empty — the Spotify tab fills those in.
