    Connect Spotify

    This needs a Spotify app of your own. It is free and takes about a minute.

    1. Open developer.spotify.com/dashboard and click Create app.
    2. Add this exact Redirect URI:
      …
    3. Tick Web API, save, then copy the Client ID.
    4. Put it in the compose file as SPOTIFY_CLIENT_ID and restart.
    Spotify refuses localhost and requires HTTPS for anything that is not a loopback address, so the redirect must be 127.0.0.1 and you must connect from a browser on the server itself. Once connected, the token is stored server-side and everyone on the network can use it.

    Get a CSV from Exportify

    Use this when you would rather not connect Spotify here. Exportify is a separate site that turns a Spotify playlist into a CSV file.

    1. Open exportify.app and click Get Started.
    2. Log in with Spotify and allow read-only access to your playlists.
    3. Find the playlist you want and click its export button to get a .csv file.
    4. Drop that file below.
    Drop the CSV here, or click to choose .csv only

    The playlist name becomes the folder name, and it gets the CSV and an .m3u alongside the tracks. Tracks you already have are skipped.
